# Pomodoro Timer

A focused work timer with short breaks and a longer break every four focus sessions. Create tasks with notes, projects, and estimated Pomodoros; select a task to track its completed focus sessions. Tasks and progress are saved in your browser.

This is the full version of the [Pomodoro timer side project](https://vuieee.github.io/projects/pomodoro-timer/), with task planning and project tracking. Its typography, colors, sticky navigation, and scroll fade follow the main portfolio site. Create tasks with notes, projects, and estimated Pomodoros; select a task to track its completed focus sessions. Tasks and progress are saved in your browser.

## Run locally

Open `index.html` in a browser, or publish this repository with GitHub Pages at `https://vuieee.github.io/pomodoro-timer/`. No build step or external dependencies are required.

## Search indexing

The page includes a descriptive title and summary, canonical URL, social-sharing metadata, and structured data. Search engines can index it once it is published at its public URL. To help them find it:

1. Enable GitHub Pages in the repository settings and use the public site URL.
2. Add the site in Google Search Console, verify ownership, and request indexing for the homepage.
3. Keep the canonical URL in `index.html` aligned with the published URL.

Indexing and search appearance are controlled by search engines and may take time; metadata alone cannot guarantee placement.
