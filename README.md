# Pomodoro Timer

A focused work timer with short breaks and a longer break every four focus sessions. Create tasks with notes, projects, and estimated Pomodoros; select a task to track its completed focus sessions. Tasks and progress are saved in your browser.

This is the full version of the [Pomodoro timer side project](https://vuieee.github.io/projects/pomodoro-timer/), with task planning and project tracking. Its typography, colors, sticky navigation, and scroll fade follow the main portfolio site.
